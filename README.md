Made as a submission to a game jam with a "Gravity" theme

## Table of Contents

1. [Installation](#installation)
2. [Controls](#controls)
3. [Gameplay](#gameplay)
4. [Assets](#assets)

## Installation

1. Clone the repository:
```bash
   git clone https://github.com/LZimm1/ManOnTheMoon.git
```
2. Open the project in Unity Hub.
3. Press **Play** in the Unity Editor to start the game.

## Controls

- **Arrow Keys** or **WASD**: Move
- **Spacebar**: Jump
